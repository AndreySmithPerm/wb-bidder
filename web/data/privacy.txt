ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ И ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ

1. ОБЩИЕ ПОЛОЖЕНИЯ
1.1. Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сервиса WB-Bidder 
Исполнителем (Самозанятый Кузнецов А.В., ИНН 590303699646).
1.2. Целью обработки данных является обеспечение работоспособности Сервиса автоматического биддинга, регистрация 
аккаунтов и проведение финансовых транзакций.

2. СОСТАВ СОБИРАЕМЫХ ДАННЫХ
2.1. Сервис собирает и обрабатывает следующие данные Пользователей:
- Адрес электронной почты (Email) или Логин — для аутентификации.
- Хэш-код пароля — для безопасного входа.
- API-токены маркетплейса Wildberries (раздел «Реклама») — для технического взаимодействия с API Wildberries по 
управлению ставками.

3. ПРАВИЛА РАБОТЫ С API-ТОКЕНАМИ WILDBERRIES
3.1. Предоставляемые Пользователем API-токены Wildberries используются Сервисом исключительно в автоматическом 
режиме для отправки запросов к официальным шлюзам маркетплейса с целью получения параметров аукциона и изменения 
ставок CPM.
3.2. Все API-токены хранятся в базе данных PostgreSQL в зашифрованном виде. Доступ Исполнителя к токенам полностью 
исключен.
3.3. Исполнитель обязуется не передавать API-токены, ID рекламных кампаний и ключевые слова Пользователей третьим 
лицам ни при каких обстоятельствах.

4. СРОКИ ОБРАБОТКИ И БЕЗОПАСНОСТЬ
4.1. Данные хранятся в течение всего срока использования Пользователем Сервиса. В случае удаления аккаунта 
Пользователя, все связанные данные (включая токены и логи) безвозвратно удаляются из базы данных в течение 
24 часов.
4.2. Для защиты сессий используется шифрование трафика (SSL) и JWT-токены авторизации.
